Block 1 · Sigmoid and logistic regression

Sigmoid function and its properties
$$\sigma(z)=\frac{1}{1+e^{-z}}$$ $$\sigma(0)=0{,}5$$ $$\sigma(-z)=1-\sigma(z)$$ $$\sigma'(z)=\sigma(z)\,\bigl(1-\sigma(z)\bigr)$$

Context: maps any real number z to a value between 0 and 1, like an on/off switch. The derivative is written with the function itself, which simplifies the chain rule.

TermWhat it isWhat it is for
$z$Input of the function (linear score, $z=wx+b$).The farther from the decision line, the larger $|z|$.
$e$Euler's number (about 2.718).Base of the exponential that bends the curve into an S.
$\sigma'(z)$Derivative of the sigmoid (max 0.25).Appears in the chain rule of the gradient.
Chain rule for the weight
$$\frac{\partial L}{\partial w}=\underbrace{-2(y-\hat{y})}_{\text{error}}\;\cdot\;\underbrace{\hat{y}(1-\hat{y})}_{\sigma'(z)}\;\cdot\;\underbrace{x}_{\text{input}}$$
$$\text{class}=\begin{cases}1,&\hat{y}\ge 0{,}5\\[2pt]0,&\hat{y}<0{,}5\end{cases}$$ $$w\leftarrow w-\eta\,\frac{\partial L}{\partial w}$$

Context: the loss reaches w through three steps (w → z → ŷ → L), so the derivative is the product of the derivative of each step.
